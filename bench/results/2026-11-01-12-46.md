## Notes

Total cost ≈ $1.79 for 18 sessions.

- Rescored per screen (route) instead of per session: fcs run 2 was marked inconsistent only because session 1 also
  built the detail page. Per screen, all 9 runs are consistent: none and design-md use hand-built shadcn `<Skeleton>`
  on both screens, fcs uses `<PageSkeleton>` on both.
- **The drift this task targets did not reproduce without fcs.** In a small, clean fixture that already ships the shadcn
  `skeleton` primitive, Sonnet picked skeletons every time. Differences between variants were structural, not visible:
  none used `loading.tsx` files, design-md used inline `<Suspense>`; contract violations here are convention only.
- Next: seed the fixture with the conditions under which drift happens in real projects (existing screens that already
  disagree, no skeleton primitive, other agents), then re-measure.
