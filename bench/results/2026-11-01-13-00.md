## Notes

Total cost ≈ $1.69 for 18 sessions. Fixture seeded with two legacy screens that disagree: /orders (client, `Loader2`
spinner) and /products (`loading.tsx` with hand-built `animate-pulse` blocks); shadcn `skeleton` removed for none and
design-md.

- **Drift still did not reproduce.** Every none/design-md run copied the /products pulse skeleton for both new
  screens; none copied the /orders spinner. fcs runs used `AsyncBoundary`/`PageSkeleton` on both.
- Reading: in a small project, Sonnet converges on its own prior (skeleton + Next `loading.tsx`) and copies the
  existing screen that matches it. Consistency of a choice the model already prefers is not where fcs adds value.
- Next: measure rules that go *against* the model's default (e.g. contract chooses `pattern: spinner`, textarea
  `resize: none`, required breadcrumb), where prose rules must win against the prior, and add a second agent (Codex).
